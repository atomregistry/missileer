# MISSILEER Site v0.1.0

Static cinematic website and live pUSDC escrow dashboard for MISSILEER.

- Cinematic MISSILEER homepage
- Live Cosmos Hub escrow status
- Keplr / Leap wallet connect
- Scan wallet-held pUSDC NFTs
- Display pUSDC denominations as MISSILEER roles
- Supply selected pUSDC NFTs to the production escrow
- Display wallet escrowed pUSDC
- Retrieve selected pUSDC before activation
- Admin-only first project payment panel
- Fate Engine / Legacy NFT / Game presentation sections
